================================================================
 CS 131 - Phase 1: Profiling
================================================================
 Dataset : ESA Gaia DR3 gaia_source
           121 of 3,386 files (every 28th file -> all-sky sample)
 Machine : AMD Ryzen 5 240, 6C/12T, 15.3 GB RAM
           Windows 11, Git Bash (MINGW64)
 Date    : 2026-07-26

 The files are gzip-compressed, so every command pipes through `zcat`
 to decompress on the fly. Each Gaia file also starts with 1000 comment
 lines beginning with '#', so `grep -v '^#'` strips them before counting
 (the ^ means "line starts with"). `time` reports how long a command took.
================================================================


----------------------------------------------------------------
 Acquisition (before profiling)
----------------------------------------------------------------

# Download the file index and extract the file names
$ curl -o md5.txt https://cdn.gea.esac.esa.int/Gaia/gdr3/gaia_source/_MD5SUM.txt
$ awk '{print $2}' md5.txt > allfiles.txt
$ wc -l allfiles.txt
3387 allfiles.txt        # 3386 data files + the index's own entry

# Take every 28th file so the sample is spread across the whole sky
$ awk 'NR % 28 == 1' allfiles.txt > filelist.txt
$ wc -l filelist.txt
121 filelist.txt

# Download the 121 files into data/  (25 GB, 6 parallel, ~63 MB/s)
$ xargs -a filelist.txt -P 6 -I{} curl -s -o "data/{}" \
    "https://cdn.gea.esac.esa.int/Gaia/gdr3/gaia_source/{}"
   ... 6m47s ...
$ ls data/*.csv.gz | wc -l
121

# Count the metadata lines
$ time zcat data/GaiaSource_000000-003111.csv.gz | grep -c '^#'
1000
real    0m4.8s

  Every file has a 1000-line '#' header block. This is why a plain
  csv reader chokes - it tries to parse the metadata as data.

================================================================
 5. A NUMERIC AGGREGATE   (awk)  - average of a column
================================================================

# Average the parallax column (field 10), skipping blanks
$ time zcat data/GaiaSource_000000-003111.csv.gz | grep -v '^#' \
    | awk -F',' 'NR>1 && $10!="" {sum+=$10; n++} END {print sum/n, "mas over", n, "stars"}'
0.942832 mas over 528333 stars
real    0m4.7s

  awk keeps only a running sum and a count in memory - a few bytes -
  while 223 MB streams past. Same aggregation is repeated in pandas
  (Phase 2) and Spark (Phase 3).
